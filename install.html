⚡ Approval System UI

Install the bookmarklet to inject the new approval interface into Workbench

Installation

1
Show your bookmarks bar (Cmd+Shift+B on Mac, Ctrl+Shift+B on Windows)
2
Drag the button below to your bookmarks bar
3
Navigate to Workbench and click the bookmarklet to activate the new approval UI
⚡ Approval System UI
Note: After installing, go to https://workbench.mosaic.amazon.dev/ and click the bookmark. The new Approval System UI will appear as an overlay. Click the × button to dismiss it.

Alternative: Manual Install

Create a new bookmark and paste this as the URL:
